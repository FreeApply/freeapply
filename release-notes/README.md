## Version numbers
`MAJOR.MINOR.PATCH`, for example 1.4.2:
- **PATCH** (1.0.**1**): fixes and small improvements.
- **MINOR** (1.**1**.0): new features or settings.
- **MAJOR** (**2**.0.0): changes that ask something of you, such as redoing part of setup.

Every legal document shows the version of the release it ships with. When the text of one changes, its release note
says what changed under **Legal**, and the dashboard asks you to accept again. A release that leaves the texts
unchanged never asks.

## What each note contains
- A one-line summary, also shown in the app's update notice.
- **New**, **Changed**, **Fixed**: what is different, in plain words.
- **Legal**: which documents changed and how, or that none did.
- **Upgrading**: anything you need to do.
